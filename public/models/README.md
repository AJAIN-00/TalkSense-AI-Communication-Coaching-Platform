# TalkSense Static Models Directory

Place your photorealistic 3D human GLB model here:
- **Filename**: `avatar.glb`
- **Path**: `/public/models/avatar.glb`

## GLB Requirements:
1. **Format**: Binary GLTF (.glb)
2. **Morph Targets**: Must include standard ARKit blend shapes for facial expressions and visemes (e.g., `eyeBlinkLeft`, `eyeBlinkRight`, `eyeLookInLeft`, and mouth shapes like `viseme_aa`, `viseme_O`, `viseme_U`, etc.).
3. **Rig**: Fully rigged head/body.
